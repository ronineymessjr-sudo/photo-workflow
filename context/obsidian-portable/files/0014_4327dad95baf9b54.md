# 站立持花

## 动作要点

1. **站姿**：重心微移，不要双脚平行站立，身体形成微妙曲线
2. **手部**：左手轻拈花枝（腊梅/桃花），右手呈兰花指微微提起
3. **眼神**：眉眼低垂，看手中花枝或斜下方，营造内敛感
4. **头部**：头微微偏向持花手一侧，但不要过度歪头

## 关键细节

- 兰花指要自然，食指与中指微微上翘，大拇指轻触无名指
- 肩部放松，避免耸肩
- 腰间可微微扭转，增加身体线条感

## 推荐参数

| 参数 | 推荐值 |
|------|--------|
| 焦段 | 85mm-135mm |
| 光圈 | f/1.4 - f/2.0 |
| 光线 | 侧逆光（轮廓光） |
| 高度 | 平拍或微微俯拍 |
| 构图 | 三分法，主体偏右 |

## 适用主题

- 温婉书卷气
- 深闺才女
- 春日踏青
