# 侧坐案前

## 动作要点

1. **坐姿**：侧身坐于案几旁，上身微转，不要正对镜头
2. **手部**：单手轻拈花枝/珍珠，另一手自然置于膝上
3. **眼神**：视线投向斜上方或看手中物，不看镜头
4. **身体**：肩、胯形成微小三才转折，身体有曲线感

## 关键细节

- 坐姿忌僵硬，腰背挺直但肩部放松
- 手部动作是重点——兰花指、轻捻珍珠都很有古韵
- 可在身前地面散落珍珠/花瓣增加氛围
- 利用倒影增加画面纵深感（地面铺深色亚克力板）

## 推荐参数

| 参数 | 推荐值 |
|------|--------|
| 焦段 | 85mm |
| 光圈 | f/1.4 - f/1.8 |
| 光线 | 侧柔光（模拟窗光） |
| 高度 | 平拍或微微俯拍 |
| 构图 | 三分法，注意留白 |

## 适用主题

- 深闺才女
- 琴棋书画
- 慵懒午后
