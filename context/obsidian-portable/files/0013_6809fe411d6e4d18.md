# 回眸侧身

## 动作要点

1. **站姿**：侧身站立，身体重心略偏后
2. **头部**：头转回看镜头，眼神带淡淡清冷或回眸一笑
3. **手部**：可手持扇子、花枝，或自然垂于身侧
4. **袖口**：如果有宽袖/飘带，可利用袖口增加飘逸感

## 关键细节

- 回眸角度不要太大，30-45度最佳
- 脖颈保持自然延伸，避免双下巴
- 利用侧逆光勾勒发丝轮廓
- 眼神要有故事感——若有所思或清冷疏离

## 推荐参数

| 参数 | 推荐值 |
|------|--------|
| 焦段 | 85mm-135mm |
| 光圈 | f/1.8 - f/2.8 |
| 光线 | 侧逆光（勾勒轮廓） |
| 高度 | 平拍或微微俯拍 |
| 构图 | 三分法，主体偏左 |

## 适用主题

- 清冷仙气
- 回眸一笑
- 侧颜杀
