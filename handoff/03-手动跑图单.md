# 手动跑图单（S01 古风汉服庭院 · 9 镜）

你自己在 ChatGPT 里出图，这套系统只负责三件事：**锁条件、收图、质检**。按下面六步走，一步都别跳。

---

## 第 0 步：准备三张参考图（最容易被跳过，但决定成败）

| 角色 | 找什么样的图 | 不要用什么样的图 |
|---|---|---|
| **人物参考** | 同一位模特的正脸或 45° 侧脸，光线均匀、无滤镜、能看清五官与发型 | 大头贴式磨皮照、强滤镜、侧脸过度遮挡 |
| **场景参考** | 实际要拍的那处园林（月洞门、回廊、石阶），白天散射光 | 网上的网红打卡照（会带来不存在的建筑） |
| **风格参考** | 你想要的成片质感：胶片颗粒、低饱和、柔和光比 | AI 生成的图（会形成自我循环，越生越假） |

只收 JPEG / PNG / WebP，单张 ≤ 8MB。三张必须角色分明——**风格参考别塞成人物参考**，这是最容易搞错的一步。

---

## 第 1 步：导入分组契约

打开 `http://127.0.0.1:8123/`，在"建立分组"里点 **导入契约 JSON**，选：

```
handoff/S01-style-hanfu-court.json
```

导入后你会看到：9 个镜头、锁定字段（场地=江南园林庭院、天气=阴天散射、时间=白天、调色=低饱和玉青）、三档参考 pending。

---

## 第 2 步：上传三张参考图

在"三张参考图"区，人物 / 场景 / 风格各上传一张。

上传即入库（内容寻址），成功后徽章变"已确认"、下方出现缩略图。**这一步没做完，后面全是灰的**——服务端会 409。

---

## 第 3 步：确认主参考图

点 **确认主参考图（人工）**。

这步的意思是：确认人物参考图里那张脸就是这组的锚。主图没确认，生成一律被拒（`CONTINUITY_MASTER_UNCONFIRMED`）。

---

## 第 4 步：出图（两种打法，选一种）

### 打法 A：逐镜出（推荐，可控）

点某镜的 **交接卡**：

1. 复制提示词 → 粘进 ChatGPT
2. 下载三张参考图 → 一起拖进对话框
3. 说明一句：`keep the same person, outfit and location as the reference images`
4. 出图后存成卡上写的文件名（如 `style-hanfu-court__01.png`）

优点：每镜可控、能单镜重做；缺点：9 次上传参考，慢。

### 打法 B：一次出九宫格（快，但单格小）

用 `PROMPTS-TEXTURE.md` 里 S01 那条提示词（3×3 接触印样，已含胶片型号与真实感约束），一次出图后裁成 9 格，按 `style-hanfu-court__01.png … __09.png` 命名。

优点：一次调用，人物天然一致（同一次采样）；缺点：单格约 341×512，要印刷级得再单格放大。

---

## 第 5 步：回传

交接卡里的 **出图后回传**，把图传进去。系统会：存成资产 → 挂到该镜 → 记 `provider=chatgpt-web` 与锁定版本 → `qc=pending`。

---

## 第 6 步：质检（不许跳）

点该镜的 **质检**，7 项逐项判：

| 项 | 判 fail 的典型情况 |
|---|---|
| 人物身份 | 换脸了、年龄差太多 |
| 服装 | 换颜色/换款式/多了配饰 |
| 地点与天气 | 不是这处园林、晴天变阴天 |
| 景别/角度/焦段 | 该全身拍了半身、该平视拍了俯拍 |
| 人数与肢体 | 多手多指、人数不对 |
| 面部清晰 | 脸糊、畸变 |
| 风格贴近 | 塑料感、HDR 味、跟风格参考差太远 |

三项（身份 / 肢体 / 风格）勾"我已人工核对"才算完。未过 → 只重做该镜，别整组重来。

---

## 一页速查

```
导入 handoff/S01-style-hanfu-court.json
→ 上传 3 张参考（人物/场景/风格）
→ 确认主参考图
→ 逐镜：交接卡 → 复制提示词 + 拖参考图 → 出图 → 按文件名保存
→ 回传
→ 质检 7 项（3 项需人眼）
```

## 我会怎么审

你把图回传完，跟我说一声"审 S01"，我就按 7 项逐镜打分，并按真实感 8 项（皮肤毛孔 / 光比 / 颗粒 / 高光 / 虚化 / 场地磨损 / 色温混合 / 姿态）给你一份 A/B/C 判定和失败聚类——**只重做 C 档那几镜**。
