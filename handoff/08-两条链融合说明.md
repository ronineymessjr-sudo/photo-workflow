## 两边的参考图语言不一样（这是融合的真正障碍）

| 我这边（契约） | 新链路（库图） | 融得通吗 |
|---|---|---|
| `identity` 人物 | `portrait` 人脸照 | ✅ 同一件事 |
| `style` 风格/服装 | `costume` 服装 | ✅ 基本同一件事 |
| `scene` 场地 | 无 | ❗ **它没有场景图像槽位** |
| — | `pose` 姿势线稿 | ⚠️ 我这边是"构图约束"，不是参考图 |

所以 **Cloudflare 这条画笔只有两个图像槽**：人脸 + 服装。场地只能写在提示词里。

我把这个缺口做成**显式报告**（`planCloudFrames().gaps`），不藏：

```js
{ role: 'scene', reason: 'Cloudflare FLUX.2 Klein 没有场景图像槽位；场地只能写在提示词里', severity: 'warning' }
```

要场地也像素级一致，只有两条路：换有场景槽的服务（Seedream 6 张参考），或上 ControlNet depth（本地）。

## 融合做了四件事

### 1. 画笔表加了 Cloudflare（免密钥、便宜档、默认推荐）

```js
{
  id: 'cloudflare-flux-klein',
  priceTier: 'low',
  supportsReferences: true,
  maxReferences: 3,
  env: [],                  // 不要 API key
  requiresBinding: 'AI',    // 但要有 wrangler.toml 里的 [ai]
  supportsSeed: true,
}
```

关键：`env: []` 但它**不是永远可用**。`recommendProvider({ bindings })` 会检查绑定是否存在——没绑 `[ai]` 就不推荐它，不会假装能出图。

实测两种状态：

```
bindings: {}        → recommended: manual-chatgpt-web,  apiReady: []
bindings: {AI:{}}   → recommended: cloudflare-flux-klein, manualOnly: false
```

这就是你要的"manualOnly 变 false"——**而且不用你去注册任何账号**，Worker 部署了就能用。

### 2. 契约白名单加了它，标明两个图像槽

```js
'cloudflare-flux-klein': {
  supportsReferences: true,
  roles: ['identity', 'scene', 'style'],
  maxReferences: 3,
  imageSlots: ['identity', 'style'],   // 只有这两个真的上传
  supportsSeed: true,
}
```

三档参考仍然必须全部确认（一致性原则不放松），但只有两张会作为图像上传。

### 3. 生成器加了 Cloudflare 适配器（一次一镜，绝不批量）

`api/continuity-generation.mjs` 新分支：

- 没绑 `[ai]` → **503**「这个部署没有绑定 Workers AI」，带 `details.missing`
- 参考图不足两张 → **409**
- 上游失败 → **502**，不吞错
- 成功 → 结果按内容寻址存成资产，`qc.verdict = "pending"`（生成层不自评）

竖幅 → 768×1024，横幅 → 1024×768。

### 4. 融合桥：契约直接变 Cloudflare 请求

`api/continuity-cloudflare-bridge.mjs`：

```js
contractShotToCloudInput(group, shotId, { aspectRatio, seed })
// → { brief, scene_brief, shot_contract{...}, reference_brief{...}, seed, candidate_count: 1 }

planCloudFrames(group, shotIds)
// → { frames: [{shotId, file, slots}], gaps: [...], canGenerate: true/false }

generateContractShot({ group, shotId, ai, readAsset, store })
// → 门禁 → 取图字节 → 一次调用 → 落资产 → qc: pending
```

复用它的参数（4 步、尺寸表、模型），但**参考图字节来自契约里的资产**——这是融合的核心价值：你上传的那张脸真的会被传上去，而不是换成库里的模特。

## 还不能自动跑的原因（诚实）

| 项 | 状态 |
|---|---|
| 代码 | ✅ 通了 |
| 本地 `wrangler dev` | ⚠️ 本地没有 `[ai]` binding（Workers AI 只在部署环境或 `--remote` 下有） |
| Cloudflare 登录态 | ⚠️ `npx wrangler whoami` 本机没返回（未登录或网络） |
| R2 存储 | ⚠️ 未绑定 `CONTINUITY_ASSETS`，参考图落本地磁盘 |

所以现在**真出图需要**：`wrangler login` → `wrangler dev --remote`（或直接部署）→ 面板里选 Cloudflare 画笔 → 生成。
