# 12 · 同脸方案调研与选型（2026-11-07）

给「那边」看的版本。结论先行，理由和参数在后面。

## 一句话结论

**换画笔：从 Cloudflare FLUX 换到火山方舟 Doubao-Seedream 4.0。**

原因只有一个：**FLUX 没有身份机制，Seedream 有。**

- FLUX.2 klein 的模型目录里**没有任何 face embedding 模型**，它把参考图当风格提示，每次生成都重采样一张脸
- Seedream 4.0 官方定位就是"基于主体一致性的多图融合"，且支持**单图生组图**（一次出最多 14 张内容关联的图）

价格 0.2 元/张，比 FLUX 贵约 3 倍，但**一次能出整组**，总成本反而接近。

## 为什么是 Seedream，不是 fal

### 能力对比

| | FLUX klein | **Seedream 4.0** |
|---|---|---|
| 参考图上限 | 4 张 | **14 张** |
| 提示词 | ~512 token，**只能英文** | **300 汉字 / 600 英文词，原生中文** |
| 一次出几张 | 1 张 | **最多 14 张内容关联**（单图生组图） |
| 宽高比 | ≤16:9 | **[1/16, 16]** |
| 分辨率 | ≤2K | **2K / 4K** |
| 身份机制 | 无 | 官方称"主体保持一致性处于世界头部" |

**"单图生组图"这一条就是决定性的。** 我们的需求本来就是"一次拍摄出一套组图"，它原生支持：给一张参考 + 一段描述，一次返回 14 张内容关联的图 —— 而不是我一张张调、每张都重新采一张脸。

### 成本对比

| 场景 | FLUX | Seedream |
|---|---|---|
| 单张 | ¥0.06 | ¥0.2 |
| 一次拍摄 9 张 | ¥0.54（但脸会漂） | ¥1.8（脸一致） |
| 需要重出的比例 | 高（脸漂就废） | 低 |

按"有效张数"算，Seedream 更划算。

## 接口（已经写好适配器，只等 key）

```http
POST https://ark.cn-beijing.volces.com/api/v3/images/generations
Authorization: Bearer $ARK_API_KEY
Content-Type: application/json

{
  "model": "doubao-seedream-4-0-250828",
  "prompt": "（中文，≤300 字）",
  "image": ["data:image/png;base64,...", "..."],   // 最多 14 张
  "size": "2K",
  "response_format": "url",
  "watermark": false,
  "sequential_image_generation": "disabled"        // 改成 "auto" 可一次出组图
}
```

关键参数说明：

| 参数 | 作用 |
|---|---|
| `image` | 参考图，支持 Base64 或 URL，**4.0 最多 14 张** |
| `sequential_image_generation` | `"auto"` = 一次出多张内容关联的图；`"disabled"` = 单张 |
| `sequential_image_generation_options.max_images` | 组图数量上限 |
| `size` | `"2K"` / `"4K"`，或具体像素 |
| `watermark` | 建议 `false`（我们的 FLUX 之前被盗水印，后处理过） |

提示词建议（官方）：**中文 ≤300 字**。这比 FLUX 的 512 token 宽松，而且不用翻译 —— 我们方案里那些中文描述可以直接用，不用再走 llama 翻译。

## 保脸的三层机制（换到 Seedream 后）

1. **多图参考**：脸 + 服装 + 上一张成片，最多 14 张一起给（FLUX 只给 4 张）
2. **锚点链式编辑**：第一张验收后作为锚点，后续每张都以它为基础改机位（已实现）
3. **组图批次**：一次请求出多张内容关联的图（Seedream 原生，FLUX 做不到）

这三层叠起来，才谈得上"同一次拍摄"。

---

## 如果 Seedream 还不够（备选）

- **fal.ai FLUX PuLID**（$0.033/MP，商业可用）：单张脸的 ID embedding，保脸最直接
- **fal.ai Face LoRA**（$2 训练一次）：把这个人训成 LoRA，之后每次生成都带上，**一致性最强**，但只适合固定模特长期使用
- **本地 InstantID / IP-Adapter FaceID**：效果好但**许可证是 research only / not for commercial use**，商用有风险
