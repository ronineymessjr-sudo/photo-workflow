## 生成与视觉初筛（已实现）

### 图像服务适配器

| provider | 适配器 | 需要的环境变量 |
|---|---|---|
| `gpt-image-2` | `openai-images-edits`（`POST /v1/images/edits`，三张参考作为 `image[]` 部件） | `OPENAI_API_KEY`，可选 `OPENAI_BASE_URL`、`CONTINUITY_IMAGE_MODEL` |
| `flux-kontext` / `sdxl-ipadapter` | `reference-json`（自建网关：`{prompt,size,aspect,seed,references:[{role,assetId,dataUrl}]}`） | `CONTINUITY_IMAGE_ENDPOINT` + `CONTINUITY_IMAGE_KEY` |

行为约定：

- **一次调用只出一镜**，绝不循环；
- 缺凭据 → `503 GENERATION_NOT_CONFIGURED`，并在 `details.missing` 里列出缺哪个变量；
- 参考图读不到 → `409 GENERATION_REFERENCE_MISSING`，**不降级成纯文生图**；
- 生成结果按内容寻址存成资产，返回 `image.assetId / image.path`；
- 生成层返回 `qc.verdict = "pending"`，**规划/生成模型不自评**。

### 视觉初筛

`POST /api/continuity/prescreen`，参数 `{ group, shotId, imagePath | imageDataUrl, scores }`。

- 只预筛三项：`wardrobe` / `place-weather` / `shot-spec`（身份、肢体、风格仍必须人眼）；
- 规则**不对称**：视觉说 fail → 可以直接变成"重做该镜"；视觉说 pass → 只能记为 `unknown`，永远不能把一张图判成通过；
- 缺 `DEEPSEEK_API_KEY` → `available: false` + 原因，全部保持未判定；
- 返回 `merged`，是"视觉建议 + 人工分数"合并后的结果，UI 直接回填质检表。

### 环境变量速查

```bash
# 生成（二选一或都配）
OPENAI_API_KEY=...                 # gpt-image-2
CONTINUITY_IMAGE_ENDPOINT=...      # flux-kontext / 自建网关
CONTINUITY_IMAGE_KEY=...

# 视觉初筛
DEEPSEEK_API_KEY=...
CONTINUITY_VISION_MODEL=deepseek-vl2   # 可按实际可用的视觉模型改
```

生产环境记得建 R2 桶并绑定为 `CONTINUITY_ASSETS`，否则参考图会落进内存（重启即丢，接口会返回 `durable: false`）。
