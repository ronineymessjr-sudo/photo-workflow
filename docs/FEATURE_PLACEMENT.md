# V2 功能归属

## 七个正式页面

1. 工作台：项目状态、下一步建议、消息与风险。
2. 参考数据库：人工参考、Pexels、Obsidian、验证状态。
3. 方案中心：Agent 草稿、人工批准、预选/正式方案、镜头与 PDF。
4. 日程与现场执行：shoot-call、月历、普通任务、镜头现场记录。
5. LUT 与后期交付：`.cube`、三栏预览、备份、选片、反馈和交付。
6. 复盘与知识回流：评分、经验、Markdown、Obsidian 写入。
7. 系统与迁移：备份、Classic 数据迁移、完整性审计和架构状态。

## 不再独立存在

- 报价计算器：废弃。
- 消息看板：整合到工作台。
- 批量参考图与 Obsidian：整合到参考数据库。
- 拍摄日程与现场镜头：统一到日程页面。
- 数据迁移和备份：统一到系统页面。

## Classic 规则

`legacy/index.html` 只作为功能对照。若 Classic 有 V2 尚缺的能力，应提炼需求与数据结构后在 V2 重新实现，而不是继续修改 Classic DOM。
