# V2 与 Classic 功能完成度

状态定义：

- **完成**：V2 已具备正式实现并有自动化验证。
- **基础完成**：主流程可用，但 Classic 仍有更高级交互。
- **待迁移**：仅存在于 Classic 或工具脚本。
- **废弃**：明确不迁移。

## 下一轮 Codex 优先级

### P0

1. 在 GitHub Actions 或本机完成完整 V2 浏览器测试。
2. 使用真实飞书 Base 验证八表字段、冲突和删除墓碑。
3. 使用真实 Obsidian Vault 验证搜索、读取和写入权限边界。
4. 对生产旧数据执行 Dry Run，人工核对后再 Commit。

### P1

1. 把设备、场地、人物管理做成 V2 独立资源页。
2. 增强镜头参考匹配、锁定、拒绝和关系可视化。
3. 补齐多格式导出和拍摄发布包。
4. 为 LUT 增加授权来源目录和用户照片临时预览，不将原图写入飞书。

### P2

1. EXIF、内容哈希、感知哈希和本地素材索引。
2. 小红书/抖音收藏 Inbox 与人工审核。
3. 向量检索和视觉相似度。
4. 天气、日照、地图与专业 Agent 评测。
