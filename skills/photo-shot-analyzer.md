# PhotoShotAnalyzer - 图片拍摄方案分析技能

## 功能说明

输入一张摄影参考图 URL，分析图片构成并输出完整的拍摄方案指南。

## 使用场景

当用户想要：
- 根据参考图复制类似风格的拍摄效果
- 了解参考图的光线布置和设备参数
- 学习特定风格的拍摄技巧
- 生成完整的拍摄方案草稿

## 输入

- 图片 URL（必填）
- 目标风格标签（可选，如：复古、时尚、古风等）

## 输出结构

### 1. 灯光分析 (Lighting Analysis)
```
- 光线方向: [正面光/侧光/逆光/顶光/底光]
- 光线质量: [硬光/软光/混合光]
- 光线色温: [暖色/中性/冷色] + 估算 Kelvin 值
- 主光源: [描述主要光源]
- 补光方案: [是否有补光，方向和强度]
- 阴影: [软硬程度，方向，是否有边缘光]
```

### 2. 调色分析 (Color Grading)
```
- 整体色调: [暖色调/冷色调/中性/低饱和/高饱和等]
- 主色调: [具体颜色描述，如：橙色、青色、墨绿等]
- 色调分离: [高光/阴影的颜色偏移]
- 对比度: [高中低]
- 暗角/Vignette: [有/无，程度]
- 颗粒感: [有/无，复古程度]
- 推荐 LUT/预设: [可用的 Lightroom/Capture One 预设方向]
```

### 3. 设备清单 (Equipment List)
```
【灯光设备】
- 主灯: [具体型号推荐，如 Godox AD600 Pro]
- 辅灯: [如果有]
- 柔光附件: [伞/柔光箱/透射伞/反光板]
- 束光筒/格栅: [是否有用]
- 反光板: [尺寸和颜色]

【环境设备】
- 烟雾机/干冰: [是否需要，效果描述]
- 鼓风机/风扇: [用于头发飘动或烟雾]
- LED 灯板: [颜色/位置/用途]
- 蜡烛/火把: [如果用到火焰效果]
- 特殊道具灯: [霓虹灯管/串灯等]

【相机设备】
- 推荐机身: [全画幅/残幅建议]
- 推荐镜头焦段: [具体 mm 数 + 推荐理由]
- 滤镜: [ND/CPL/黑柔等]
```

### 4. 拍摄参数 (Shooting Parameters)
```
- 推荐焦段: [具体 mm]
- 光圈: [f/1.4~f/2.8 大光圈 或 f/5.6~f/8 小光圈]
- 快门速度: [根据光线和是否需要运动模糊]
- ISO: [建议范围]
- 对焦方式: [单点/区域/眼控]
- 建议机位高度: [眼平/低角度/高角度]
```

### 5. 环境与天气 (Environment & Weather)
```
- 最佳时间: [黄金时段/蓝调时段/正午可用/室内全天]
- 天气要求: [晴天/阴天/雨天特殊效果/不限]
- 室内/户外: [场地类型]
- 背景建议: [纯色/虚化/环境交代]
- 温度/季节: [如果涉及自然光]
```

### 6. 拍摄执行要点 (Execution Tips)
```
- 关键步骤: [3-5 个核心拍摄步骤]
- 常见错误: [容易出问题的地方]
- 创意延伸: [可变化的方向]
```

## 技术实现

在 photo-workflow 网站中的实现：

1. 用户粘贴/上传参考图 URL
2. 调用分析函数，传入图片 URL 和当前选择的风格
3. 显示 AI 分析结果
4. 用户可将分析结果一键应用到方案生成表单中
