# PhotoAtelier workspace visual direction

- Scope: presentation only; retain all JavaScript, APIs, data and navigation behavior.
- Palette: neutral graphite in dark mode, white and cool gray in light mode.
- Accent: muted green, reserved for selection and primary actions.
- Typography: native system sans-serif, zero tracking, existing type hierarchy.
- Layout: retain existing responsive workspace, forms and result views.
- Density: balanced; no decorative hero or background imagery in work surfaces.
- Components: solid surfaces, thin borders, restrained semantic status colors.
- Exclude: silk wallpaper, background mesh, noise, vignette, floating glow blobs.
- Images: preserve actual references, equipment imagery and generated candidates.
- Theme compatibility: existing dark, light, sunrise and sunset controls remain.
- Acceptance: unchanged inline scripts, integration tests, dark/light desktop/mobile
  checks, no wallpaper network requests and no horizontal viewport overflow.
