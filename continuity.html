连续性分组

一次拍摄 = 一份锁定契约 + 三张角色化参考 + 主图确认 + 逐镜请求 + 每图质检。没有"一条提示词出九张"这种按钮。

1. 建立分组

2. 三张参考图（角色分开，缺一不可）

主图未确认前，服务端会直接拒绝生成。

3. 逐镜请求

选中某镜的"取请求"，这里会显示实际发出去的请求（含 seed、参考角色、锁定字段）。

4. 交接卡（在 ChatGPT 里出图）

选中某镜的"交接卡"：复制提示词、下载三张参考图、出图后直接回传。回传的图会存进资产并按同一套规则质检。

5. 质检

选中某镜的"质检"后在这里逐项判定。未过只重做该镜，不重做整组。

规则

  • 锁定字段只能来自原始需求，镜头层不得改写。
  • 参考图分人物 / 场景 / 风格三档，风格参考必须来自你自己的图库。
  • 主参考图必须人工确认，之后才允许批量生成。
  • 每个镜头单独请求，携带同一套锁定条件与同一组参考。
  • 不支持参考图的模型一律拒绝，不做纯文字降级。
  • 每张图都必须过质检；关键项（身份 / 肢体 / 风格）需人眼确认。
